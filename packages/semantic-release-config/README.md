# @xrdev_38/semantic-release-config

Semantic Release configuration for automated changelogs and npm publishing.

## Features

- Automatic versioning and changelog generation
- Publishes to npm and GitHub Releases

## Installation

```bash
pnpm add -D semantic-release @semantic-release/changelog @semantic-release/github @semantic-release/npm @xrdev_38/semantic-release-config
```

## Usage

In your `release.config.js`:
```js
module.exports = require("@xrdev_38/semantic-release-config");
```
