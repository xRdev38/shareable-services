# @xrdev_38/postcss-config

Shareable PostCSS configuration with common plugins.

## Features

- `postcss-preset-env` for modern CSS features
- `autoprefixer` for cross-browser compatibility
- `cssnano` for minification

## Installation

```bash
pnpm add -D postcss postcss-preset-env autoprefixer cssnano @xrdev_38/postcss-config
```

## Usage

In your `postcss.config.js`:
```js
module.exports = require("@xrdev_38/postcss-config");
```
