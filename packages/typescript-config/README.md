# @xrdev_38/typescript-config

Shareable, strict TypeScript configuration for modern apps and libs.

## Features

- Strict options for code safety
- Ready for libraries and monorepos
- Easy to extend for custom needs

## Installation

```bash
pnpm add -D typescript @xrdev_38/typescript-config
```

## Usage

In your `tsconfig.json`:
```json
{
  "extends": "@xrdev_38/typescript-config"
}
```
