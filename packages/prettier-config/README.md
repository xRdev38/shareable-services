# @xrdev_38/prettier-config

Shareable, opinionated Prettier configuration for all code formats.

## Features

- Enforces consistent code style (JS, TS, CSS, SCSS, JSON, Markdown)
- Designed to work with ESLint & Stylelint

## Installation

```bash
pnpm add -D prettier @xrdev_38/prettier-config
```

## Usage

Add to your `package.json`:
```json
{ "prettier": "@xrdev_38/prettier-config"}
```
Or create a `prettier.config.js`:
```js
module.exports = require("@xrdev_38/prettier-config");
```
