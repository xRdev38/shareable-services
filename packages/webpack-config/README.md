# @xrdev_38/webpack-config

Shareable Webpack configuration for building modern JS/TS/CSS/SCSS projects.

## Features

- Handles JS, TS, CSS, SCSS out of the box
- Easily extendable for app or library builds

## Installation

```bash
pnpm add -D webpack webpack-cli babel-loader style-loader css-loader sass-loader @xrdev_38/webpack-config
```

## Usage

In your `webpack.config.js`:
```js
module.exports = require("@xrdev_38/webpack-config");
```
