# @xrdev_38/commitizen-config

Commitizen adapter for Conventional Commits.

## Features

- Makes writing standardized commits easy and interactive

## Installation

```bash
pnpm add -D commitizen cz-conventional-changelog @xrdev_38/commitizen-config
```

## Usage

In your `.czrc` or `package.json`:
```json
{
  "config": {
    "commitizen": {
      "path": "./node_modules/@xrdev_38/commitizen-config"
    }
  }
}
```
