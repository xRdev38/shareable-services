# Shareable Frontend Services 🛠️

Ce projet contient une collection de configurations partagées pour les outils frontend modernes, utilisables dans tous vos projets JavaScript, TypeScript, CSS et SCSS.

## Packages disponibles

- **@xrdev_38/eslint-config**
- **@xrdev_38/stylelint-config**
- **@xrdev_38/prettier-config**
- **@xrdev_38/jest-config**
- **@xrdev_38/typescript-config**
- **@xrdev_38/commitlint-config**
- **@xrdev_38/commitizen-config**
- **@xrdev_38/lint-staged-config**
- **@xrdev_38/postcss-config**
- **@xrdev_38/semantic-release-config**
- **@xrdev_38/webpack-config**

## Installation

```bash
pnpm install --save-dev @xrdev_38/eslint-config
```
